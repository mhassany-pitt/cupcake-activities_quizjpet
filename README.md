# Cupcake QuizPET & QuizJET Code Tracing Activities

Parameterized code tracing activities transformed from the 447 QuizPET and QuizJET questions in the ADAPT / Smart Learning Content (SLC) Catalog:

https://adapt2.sis.pitt.edu/next.course-authoring/#/catalog-v2

## Contents

This repository contains **343 unique activity folders** representing **424 parameterized code tracing activities** conforming to the Cupcake `parameterized-code-tracing/0.1.0` specification:

- **Language Separation**: Divided at top level into `python/` (QuizPET) and `java/` (QuizJET).
- **Python Activities (`python/`)**: 112 unique base problem folders representing 193 activities. Includes bilingual support with paired English (`_en.yaml`) and Spanish (`_es.yaml`) variants sharing problem folders.
- **Java Activities (`java/`)**: 231 problem folders representing 231 activities (`_en.yaml`).
- **Companion Files**: All required multi-tab source files and datasets (e.g. `people.csv`, `text.txt`, `texto.txt`, `queue.py`, `cola.py`, `binary_tree.py`, `arbol_binario.py` in Python; `Node.java`, `SLinkedList.java`, `BankAccount.java` in Java) are included alongside the drivers and declared under `includes: [...]`.
- **Differentiated Topics**: Knowledge Component topics in `pedagogy.topics` are namespaced by parser/ontology (e.g. `acos:Assign`, `alice_expert:AssigningValueVariable`, `jordan_alice:CallingStandardFunction`, `java_ontology:Array`).
- **Complete Attribution**: Full author metadata with names, academic affiliations (University of Pittsburgh, Aalto University), and university email contacts.
- **Execution-Verified Testcases**: Every activity contains an execution-verified testcase with true `stdout` generated by executing the driver and companion files. Variable-value tracing questions ("What is the final value of X?") print the variable so backend code execution directly matches the expected output.
